project name, so nothing looks broken.

## Recommended export

- **Size:** 1600 × 1000 px (16:10). The small cards reuse the same file and
  crop it from the top, so keep the important content near the top.
- **Format:** WebP, quality ~80, under 150 KB per image.
- **Content:** the live home page, from the top of the page (include the
  header/hero). No device frames, no stock photos, no other designers' work.
- **Alt text:** edit it in `js/config.js` (`imageAlt`) and in `index.html`.

A quick way to make a WebP on Windows or macOS: open the screenshot in
Squoosh (squoosh.app), set width to 1600, choose WebP quality 80, download,
and rename it to the file name above.

When you replace an image, hard-refresh the page (Ctrl/Cmd + Shift + R) to
bypass the year-long image cache.
